# Domain docs

Single-context repo. Domain, rules, and stack are documented in `CONTEXT.md`
at repo root. Architectural decisions are recorded as ADRs under `docs/adr/`:
0001 architecture overview (no backend, prerendered public pages, draft model)
0002 feature-based layout (folders, import rules, naming); 0003 Prettier and lint
rules; and 0004 pure rules used by two features live in `shared/lib`. Add a new ADR for each new architectural decision.
