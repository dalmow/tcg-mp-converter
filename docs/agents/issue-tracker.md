# Issue tracker

Issues are tracked in Linear: workspace `dalmow`, team `DAL`, project
`PTCG Tool`. Use the Linear MCP tools (e.g. `get_issue`, `list_issues`) to
read and update issues.

Code and PRs stay on GitHub: [dalmow/tcg-mp-converter](https://github.com/dalmow/tcg-mp-converter).
Use the `gh` CLI for PRs, e.g.:

```
gh pr list --repo dalmow/tcg-mp-converter
gh pr create --repo dalmow/tcg-mp-converter
```

Branch names start with the Linear identifier, e.g. `dal-12-navigation`
(Linear's suggested `gitBranchName` also works). Mention the identifier
(e.g. `DAL-12`) in the PR so Linear links it.
