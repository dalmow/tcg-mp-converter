# Issue tracker

Issues are tracked on GitHub: [dalmow/tcg-mp-converter](https://github.com/dalmow/tcg-mp-converter).

Use the `gh` CLI to interact with issues and PRs, e.g.:

```
gh issue list --repo dalmow/tcg-mp-converter
gh issue view <number> --repo dalmow/tcg-mp-converter
gh pr list --repo dalmow/tcg-mp-converter
```

Triage label `ready-for-agent` marks a spec ready for implementation. Other
labels are GitHub defaults (`bug`, `enhancement`, `question`, etc.) — no
further custom vocabulary defined yet.
