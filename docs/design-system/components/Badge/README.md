`chip-accent`: `secondary-tint-strong` background, a `secondary-border-soft` border, `radius-pill`, `micro-label` type, text set in `secondary` itself (not `ink`). One badge per deck using a card — a card used by three decks gets three badges in a row, never one badge with a combined label. An `ink-subtle` "Decks:" caption always introduces the row. A card used by no deck gets no badge at all: the word "nenhum" in `ink-subtle`, same caption weight as the label before it.
