Three variants, never a fourth. Primary (`<Button variant="primary">`): `primary` fill, a 1.5px `secondary` border — not a neutral one, that cyan-on-navy outline is this brand's one signature combination — and on hover the fill moves to `primary-hover` while the border brightens to `secondary-strong`. Danger: the same shape as primary but `danger` fill with a `danger` border, moving to `danger-hover` on hover; reserve it for a destructive confirm (Excluir, Substituir tudo) or a modal's dangerous main action. Ghost (`<Button variant="ghost">`): transparent with a `border` hairline and `ink` text, and on hover both the border and a faint fill pick up `secondary` — never fill solid on hover.

Every button is `radius-md`, `body-strong`/`ui`-weight label depending on size, and always less rounded than the panel it sits in. A disabled button (the "Copiar" button before there's anything to copy) drops to 0.45 opacity and `cursor: not-allowed`, nothing else changes. An icon-only button is square, gets `aria-label` and `title` (the rule is in the README, Iconography), and uses `radius-xs` or `radius-sm` instead of `radius-md` at its smaller sizes (28px `icon-sm`, 36px `icon-lg`) — see Button Group for two or more icon-only actions side by side.
