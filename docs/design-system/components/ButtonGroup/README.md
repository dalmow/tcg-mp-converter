For two or more icon-only actions that belong to the same row (Salvar/Excluir on a deck header, a quantity row's save action). One outer container, `radius-md`, `overflow:hidden`, height matched to the input beside it (36–44px depending on context) — never a border on the container unless the group is the row's only action. Inside, each button fills its slice solid (`primary` for a neutral action, `danger` for a destructive one) with no border of its own, and a 1px `divider-accent` seam (`rgba(100,233,238,0.5)`, not a neutral grey) sits between adjacent buttons. When a row's only valid action is destructive (a surplus row with nothing left to save), the group holds exactly one button and the divider disappears with it — never show a disabled Salvar beside it.
