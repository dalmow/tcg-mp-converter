`surface-200`, `radius-3xl`, a `border` hairline (0.14 opacity), `shadow-modal`, centered over an `overlay`-dimmed (`rgba(5,4,8,0.72)`) backdrop. Title is `modal-title`. A warning sentence inside the body is `danger-soft` — lighter than `danger` so it reads as prose, not as a control. The action row is right-aligned: a ghost `Button` "Cancelar" beside a filled confirm button. When the confirm action is destructive (replacing data, deleting), that confirm button is filled `danger`, never `primary` — the system deliberately breaks its own "main action is primary" rule here, because the main action is also the dangerous one and must look like it.
