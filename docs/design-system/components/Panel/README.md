The one card shape in the system — every DeckEditor and Manutenção category block, and the base a row-state or table sits inside. `surface-100`, `radius-2xl`, a `border-faint` hairline, `space-8` (20px) padding, `space-6` (14px) gap between the heading and whatever follows it. The DeckEditor category panels are the accepted exception: they use a `space-7` (16px) gap. The heading is `h2` with an optional icon-only action at the far right (e.g. "Adicionar carta"), never a second line of description text inside the heading row — a subtitle belongs above the panel, not inside it. Don't create a second card style for density or emphasis; stack panels, or add a row state inside one, instead.
