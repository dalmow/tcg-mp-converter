The one state pattern for a row or an inline input, used two ways: full-row (Manutenção's maintenance rows) or per-cell (DeckEditor's table inputs). Pendency is `danger-tint` background with a 1.5px `danger` border; complete is `secondary-tint` with a 1.5px `secondary` border; a no-op row that needs no action gets a 1px **dashed** `border-dashed` on `rgba(255,255,255,0.03)` instead of either status color. Where space allows (DeckEditor's table), pair the color with an icon-plus-sentence line below the row ("Linha com pendências — faltam 2 cartas") — this is the accessible reference version, and the only version that satisfies the system's own color-blind-safe bar on its own. Where a list is denser (Manutenção), color-only is used as a deliberate, documented exception — never invent a third silent variant beyond these two.
